Basic

Four isolates, each with its own surface, on three event loops. A and B have a worker each. C and D share one, a pool. They talk only through topics on the bus, which runs in a worker of its own.

  • Block keeps an isolate's loop busy for 3 s. The kernel kills a loop that stays busy for 2 s and restarts it, and the isolate reads the bus again from where it was.
  • Crash reports an error as the isolate's own. Only that isolate restarts, even in a pool.
  • Block the main thread freezes every surface on screen, while the loops behind them keep running.
main thread: -- fps

Own workers: one event loop each

Pool "shared": one worker, one event loop

A pool is a unit of failure: block C and D stalls with it, and both restart together.
